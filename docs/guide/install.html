Getting started

Install SnapAPI

SnapAPI is a Python package with a snapapi console script. Use a virtualenv so the CLI stays on a known interpreter.

From this repository

git clone https://github.com/Deekshith-07/snapapi.git
cd snapapi
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"

.[dev] adds this repository’s test extras. The watch extra is optional and pulls in watchdog for snapapi watch.

pip install -e ".[watch]"

Pinned runtime dependencies

If you want the lock-style requirements file instead of the extra:

pip install -r requirements.txt
pip install -e .

Confirm the CLI

snapapi --help
python -m snapapi --help

The process is the same either way. Exit codes: 0 all tests passed, 1 a test failed, 2 parse or usage error.

Requirements

  • Python 3.9 or newer
  • Runtime: requests, colorama, jsonschema, PyYAML
You can skip install entirely and run suites in the playground. The playground is a JavaScript interpreter plus an in-memory mock; it is not a substitute for CI.
