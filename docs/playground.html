          Mock (default): URL: empty, mock://, or Live fetch off — paths such as GET: /api/users are served in-memory.
          Seed users 1 and 2 exist; POST /api/users returns 201 and an id; PUT/PATCH/DELETE work; /jobs/:id is pending twice then ready.
          Live fetch: when the suite URL: is https://… (or http://…) and the checkbox is on, the playground uses fetch(). Browsers enforce CORS — many public APIs will fail with a network error even if curl would succeed. Stay on mock unless the target sends Access-Control-Allow-Origin.
          Supported here: SUITE, DESC, URL, TEST, HELPER, TAG, SETUP, TEARDOWN, DEPENDS, GET/POST/PUT/PATCH/DELETE/HEAD, REQUEST, BODY JSON (and form/raw), HEADER(S), QUERY, PARAM, AUTH bearer/basic, EXPECT status/body/json/header, SAVE, ${var}, SET, EXAMPLES (inline), WAIT, // comments.
          Not supported (explicit error): FILE, GRAPHQL, IMPORT, SKIP/ONLY/QUARANTINE, AUTH oauth2/digest, EXPECT schema/xpath/duration/openapi.
